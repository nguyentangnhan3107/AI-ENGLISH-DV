## 🌟 Giới thiệu tổng quan

**Eng AI For Learn** là ứng dụng học ngoại ngữ thế hệ mới, kết hợp giữa phương pháp học tập tương tác dạng game hóa (Gamified Learning Path theo phong cách Duolingo) và sức mạnh của mô hình AI từ Google Gemini. Ứng dụng mang đến trải nghiệm học tập sinh động, giúp học viên tiếp thu từ vựng, ngữ pháp, phản xạ giao tiếp tự nhiên và cải thiện phát âm một cách vượt bậc.

Đặc biệt, ứng dụng tích hợp **Chế độ Trợ Năng dành cho Người Khiếm Thị (Accessibility Voice Assistance)** sử dụng công nghệ Text-to-Speech chạy trực tiếp trên thiết bị (0ms latency, không phụ thuộc đường truyền mạng), cho phép mọi người học đều có thể tiếp cận tri thức dễ dàng.

## ✨ Tính năng nổi bật

### 1. 🗺️ Lộ trình học Gamification (Learning Snake Path)
- **Lộ trình uốn lượn trực quan**: Các bài học được tổ chức thành từng Chương (Unit), Cột mốc và Đích kiểm tra năng lực.
- **Rương kho báu & Thưởng đá quý**: Mở khóa các rương kho báu ngẫu nhiên sau khi vượt qua các mốc học tập.
- **Chuỗi ngày học tập (Streak Flame)**: Tạo động lực duy trì thói quen học tập hàng ngày.
- **Đặc quyền Eng AI PRO Trọn Đời**: Vô hạn Tim (Hearts), không giới hạn lượt làm bài tập.

### 2. 💬 Đoạn hội thoại mẫu & Đọc hiểu (Dialogue & Context)
- **Kịch bản thoại tương tác**: Đối thoại trực quan giữa **Alex (Giáo viên AI)** và **Học viên**.
- **Phát âm tức thì**: Bấm nghe phát âm từng câu thoại hoặc nghe toàn bộ đoạn kịch bản không có độ trễ.
- **Từ vựng trọng tâm (Highlights)**: Trích xuất từ mới trong ngữ cảnh kèm định nghĩa tiếng Việt, phiên âm và câu ví dụ.
- **Điểm ngữ pháp (Grammar Tips)**: Đúc kết công thức và cách ứng dụng thực tế.

### 3. 🎯 Luyện tập 20 câu hỏi chuyên sâu (Deep Assessment)
- **Đa dạng dạng bài tập**:
  - Trắc nghiệm 4 lựa chọn (Multiple Choice)
  - Sắp xếp trật tự từ tạo thành câu đúng (Word Order)
  - Ghép cặp thẻ từ vựng - nghĩa (Card Matching)
  - Luyện phát âm trực tiếp qua Micro (Speech Pronunciation Drill)
- **Âm thanh phản hồi sống động**: Hiệu ứng âm thanh khi trả lời đúng, sai, mở rương, pháo hoa chúc mừng (Sound Effects & Fireworks).

### 4. 🔊 Trợ Năng Khiếm Thị (Voice Accessibility - 0ms TTS)
- **Phím tắt nhanh `Alt + V`**: Bật/tắt trợ năng giọng nói mọi lúc trên bàn phím.
- **Tự động đọc bài học & đề thi**: Đọc to nội dung câu hỏi, từng phương án lựa chọn và kết quả đáp án ngay lập tức.
- **Đọc điều hướng màn hình**: Phát giọng nói mô tả trang khi chuyển giữa các tab học tập.
- **Chạy trực tiếp trên thiết bị**: Tận dụng Web Speech API native của trình duyệt, không có độ trễ mạng (Zero Delay).

### 5. 🤖 Trò chuyện luyện nói cùng Alex AI (Conversational Practice)
- **Phòng trò chuyện thông minh**: Đàm thoại bằng tiếng Anh theo nhiều chủ đề thực tế (Du lịch, Ẩm thực, Công việc, Thói quen...).
- **Chấm điểm & Sửa lỗi tức thì**: AI nhận xét ngữ pháp, từ vựng và gợi ý các mẫu câu trả lời tự nhiên.
- **Gợi ý phản xạ**: Cung cấp sẵn các mẫu câu để người học tự tin trò chuyện.

### 6. 📖 Sổ tay từ vựng & Từ điển Táo (Vocabulary & Smart Notebook)
- **Quản lý kho từ vựng cá nhân**: Thêm, sửa, xóa, tìm kiếm từ vựng theo chủ đề.
- **Luyện tập phát âm với AI**: Chấm điểm độ chuẩn xác của giọng nói bằng AI.
- **Đồng bộ tự động**: Tự động lưu từ vựng mới học được từ các bài học vào Sổ tay.

### 7. 📝 Đề thi AI & Thi thử năng lực (AI Test Generator)
- **Tự động tạo đề trắc nghiệm**: Theo các khối lớp (Lớp 1-12) và trình độ (Beginner, Intermediate, Advanced, IELTS).
- **Phân tích chi tiết**: Lời giải thích cặn kẽ cho từng câu hỏi sau khi hoàn thành.

## 🚀 Hướng dẫn cài đặt & Chạy ứng dụng

### Yêu cầu môi trường
- **Node.js**: Phiên bản 18 trở lên (khuyên dùng Node 20 LTS)
- **Trình quản lý gói**: `npm` hoặc `pnpm` / `yarn`
- **Trình duyệt**: Google Chrome, Microsoft Edge, Safari hoặc Firefox phiên bản mới nhất (hỗ trợ Web Speech API).

### 1. Clone repository về máy
```bash
git clone https://github.com/your-username/remix-eng-ai-for-learn.git
cd remix-eng-ai-for-learn
```

### 2. Cài đặt các gói phụ thuộc
```bash
npm install
```

### 3. Cấu hình biến môi trường
Tạo file `.env.local` ở thư mục gốc của dự án:
```env
# Khóa API Google Gemini (lấy tại https://aistudio.google.com/)
GEMINI_API_KEY=your_gemini_api_key_here
```

### 4. Khởi chạy môi trường phát triển (Development)
```bash
npm run dev
```
Ứng dụng sẽ chạy tại địa chỉ: `http://localhost:3000` (hoặc cổng hiển thị trong Terminal).

### 5. Kiểm tra lỗi mã nguồn (Lint)
```bash
npm run lint
```

### 6. Đóng gói cho môi trường Production (Build)
```bash
npm run build
```
Thư mục `dist/` sẽ được tạo sẵn sàng để triển khai lên Vercel, Netlify, Cloud Run hoặc Firebase Hosting.

## ⌨️ Phím tắt & Hỗ trợ Tiếp cận (Accessibility)

- **`Alt + V`**: Bật hoặc tắt tức thì **Chế độ Trợ Năng Khiếm Thị** (Voice Assistant).
- **Phát âm từ vựng / câu thoại**: Nhấp vào biểu tượng loa bên cạnh từng câu để nghe phát âm chuẩn bản xứ.
- **Micro phát âm**: Chạm biểu tượng Micro để nói, AI sẽ tự động phân tích và đưa ra phản hồi.
